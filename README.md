# color-631 · 6:3:1 配色配比 Skill

> 把「黄金配色法则」中唯一可确认的配比规则，做成一条可调用的设计约束。

**内容范围**：仅基于已提供的视频封面文字与分享页文案。无法确认的信息一律标为「待确认」，不补充、不外推。本仓库不包含视频素材、提取与核验过程，也不是通用配色教程。

---

## 1. 技能定位

`color-631` 是一个**配比计算工具**，不是配色教程，不做审美判断。

它只承载一条已确认的规则：画面配色划分为「主色／辅色／强调」三类，占比分别为 `60% / 30% / 10%`，即 `6:3:1`。给定总量后，输出三类角色的份数；不传入总量时，输出默认配比。

**命名理由**：名称直接锁定唯一可确认的规则——主色／辅色／强调按 6:3:1（60/30/10）分配，不指向任何通用配色知识。

## 2. 核心能力

### 2.1 已确认的规则内容

| 维度 | 结果 | 状态 |
| --- | --- | --- |
| 核心配色思路 | `6:3:1`；主色 60% / 辅色 30% / 强调 10%；封面以三个横向色块按 60% / 30% / 10% 宽度并列示意 | 已确认 |
| 具体使用方法 | 配色划分为主色、辅色、强调三类，占比分别为 60% / 30% / 10% | 部分确认 |
| 灵感 | 仅可确认问题出发点原句「配色总是乱？」；灵感来源未说明 | **待确认** |
| 适用场景 | 源材料未明确说明；仅出现话题标签（分类标签），不作解读 | **待确认** |
| 使用方法的待确认部分 | 三类颜色如何选定、分配顺序与执行步骤、各角色在画面中的具体应用位置、色值、媒介差异、例外与限制 | **待确认** |

### 2.2 可调用能力

| 命令 | 输出 | 说明 |
| --- | --- | --- |
| `node scripts/ratio.mjs` | 三行 `角色 / 百分比 / 份数` + 待确认提示 | 默认总量 100 → 60 / 30 / 10 |
| `node scripts/ratio.mjs --total <N>` | 同上，按 N 换算 | N 为任意正数；比例不随总量变化 |
| `node scripts/ratio.mjs --json` | 结构化 JSON | `pending` 字段恒存在 |
| `node scripts/ratio.mjs --check` | `PASS: 6 项自检全部通过` | 校验比例、角色、总和、待确认项保留、换算一致性 |
| `node scripts/ratio.mjs --help` | 用法说明 | — |

JSON 输出结构：`{ skill, ratio, total, roles[{ name, percent, parts, amount }], pending{ inspiration, applicableScenarios, usage[] } }`。

### 2.3 明确不提供

- 选色、色值推荐、色卡生成
- 三类角色在画面中的具体落位
- 对比度、可访问性、跨媒介适配检查
- 自定义比例、自定义角色（比例固定为 `6:3:1`，角色固定为三个）
- 其他配色法则、通用配色教学

## 3. 适用场景

### 触发

- 设计任务已确定或需要套用 `6:3:1` / `60-30-10` 配比
- 需要把画面颜色按主色／辅色／强调三类分配占比
- 需要把配比换算成具体份数
- 需要查询该法则哪些内容尚未确认

### 不触发

选色、配色方案评审、完整视觉规范、通用配色教学。遇到这类需求时，应明确告知超出本 Skill 范围。

## 5. 使用前提

1. **Node.js 18 及以上**（ESM、`node:` 内置模块）；零第三方依赖，无需安装、无需构建。已在 Node.js v24.9.0 验证。
2. `scripts/ratio.mjs` 按自身位置解析 `rules.json` 路径，与当前工作目录无关；可从任意目录以绝对路径调用。
3. 直接运行脚本无需安装；若作为 Skill 被 Agent 调用，把整个 `color-631/` 目录放入 `~/.workbuddy/skills/`。
4. `rules.json` 必须保持合法 JSON，且 `coreIdea.roles` 三项固定；`--check` 会校验其一致性。

## 6. 注意事项 / 使用边界

1. 只输出已确认的配比信息；「待确认」项原样保留，不得填充。`--json` 输出中 `pending` 恒存在。
2. 不把话题标签解读为适用场景。
3. 不把封面示意色块的具体颜色写成推荐配色；实例配图中的灰阶与描边仅用于区分三个角色，**不构成色值推荐**。
4. 不补写角色用途（例如某角色用于背景或按钮）。
5. 不引入其他配色法则或通用配色常识。
6. 不扩展到选色、色值、无障碍、跨媒介适配。
7. 输出是配比约束，不是完整设计方案；需要完整方案时明确告知超出本 Skill 范围。
8. `--total` 必须是正数；传入 `0`、负数、非数值或未知参数时，脚本报错并以退出码 `1` 结束，不输出部分结果。

## 7. 术语表

| 术语 | 含义 |
| --- | --- |
| 主色 | 三类颜色角色之一，占比 60%（6 份） |
| 辅色 | 三类颜色角色之一，占比 30%（3 份） |
| 强调 | 三类颜色角色之一，占比 10%（1 份） |
| 6:3:1 | 主色／辅色／强调的份数比，等价于 60% / 30% / 10% |
| 配比 | 三类角色在总量中的占比分配 |
| 总量 / `total` | 换算基准，任意正数，默认 100 |
| 份数 / `amount` | 某角色按总量换算得到的数值 |
| 待确认 | 已提供内容中无法确认的信息，原样保留、不填充 |
